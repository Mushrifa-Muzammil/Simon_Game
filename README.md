---

## ✨ Features

### 🎯 Core Gameplay
- **Memory Challenge** - Watch, remember, and repeat the increasing sequence of colors
- **Progressive Difficulty** - Each level adds one more color to remember
- **Streak System** - Build your combo for special animations and effects
- **High Score Tracking** - Your best score is saved locally

### ⚙️ Difficulty Levels
| Difficulty | Speed | Description |
|------------|-------|-------------|
| 🐢 EASY | 800ms | Perfect for beginners |
| ⭐ NORMAL | 500ms | Classic Simon experience |
| ⚡ HARD | 300ms | For memory masters |
| 🔥 EXTREME | 150ms | Only for the brave! |

### ✨ Special Features
- **Magic Mode** 🪄 - Toggle particle effects, confetti, and visual celebrations
- **Skip Level** ⚡ - Bypass the current level (limited use)
- **Dynamic Speed** - Game speeds up every 5 levels (except Extreme)
- **Sound Effects** - Audio feedback for each button press (fallback to Web Audio API)

### 🎨 Visual Effects
- Animated rainbow background
- 3D button press effects
- Floating particles on clicks
- Confetti celebrations for achievements
- Glowing borders and glass morphism design
- Responsive layout for all devices

---

## 🎮 How to Play

1. **Start** - Press any key to begin
2. **Watch** - Pay attention to the sequence of colored buttons
3. **Repeat** - Click the buttons in the same order
4. **Advance** - Each correct round adds one more color
5. **Don't make mistakes!** - One wrong click ends the game

### ⌨️ Keyboard Shortcuts
| Key | Action |
|-----|--------|
| `M` | Toggle Magic Mode |
| `S` | Skip current level |
| `R` | Restart game |
